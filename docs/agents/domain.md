# Domain Docs

This repository uses a single-context domain-document layout.

## Before exploring

Read:

- `CONTEXT.md`
- Relevant ADRs under `docs/adr/`

If a file does not exist, proceed without creating it automatically.

## Vocabulary

Use the terms defined in `CONTEXT.md` in specifications, Issues, tests, implementation notes, and
reviews. Do not replace them with synonyms that the glossary explicitly avoids.

## Decisions

System-wide architectural decisions live in `docs/adr/`.

If proposed work conflicts with an accepted ADR, surface the conflict explicitly instead of
silently overriding the decision.
